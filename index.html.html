📱 ALS APP INSTALLIEREN
1
Datei im Internet verfügbar machen
Die HTML-Datei muss online sein, damit dein Handy sie als App speichern kann. Der einfachste Weg ist GitHub Pages – komplett kostenlos.
2
GitHub-Konto erstellen
Geh auf github.com und klick oben rechts auf "Sign up". E-Mail eingeben, Passwort wählen, fertig. Kostet nichts.
3
Neues Repository anlegen
Oben rechts auf das + klicken → "New repository". Als Name z.B. rwe-gotcha eingeben. Haken bei "Public" lassen. Ganz unten auf "Create repository" klicken.
4
HTML-Datei hochladen
Auf der neuen Seite steht "uploading an existing file" – darauf klicken. Diese HTML-Datei per Drag & Drop ins Fenster ziehen. WICHTIG: Die Datei muss index.html heißen! (Vorher umbenennen.) Dann unten auf "Commit changes" klicken.
5
GitHub Pages aktivieren
Oben auf "Settings" klicken (Zahnrad-Tab). Links im Menü auf "Pages" klicken. Unter "Branch" von "None" auf "main" umstellen. Dann auf "Save" klicken. Fertig! Nach 1–2 Minuten ist deine App online.
6
Adresse herausfinden
Deine App ist jetzt erreichbar unter:
https://DEINNAME.github.io/rwe-gotcha/
Ersetze DEINNAME durch deinen GitHub-Benutzernamen. Diese Adresse auf dem Handy im Browser öffnen.
7
Auf dem Handy installieren
Seite auf dem Android-Handy in Chrome öffnen. Dann:
Android (Chrome)
Oben rechts auf die drei Punkte ⋮ tippen → "Zum Startbildschirm hinzufügen" oder "App installieren" wählen → "Installieren" bestätigen. Die App erscheint als Icon auf deinem Startbildschirm – wie eine echte App!
iPhone (Safari)
Unten auf das Teilen-Symbol ⬆ tippen → nach unten scrollen → "Zum Home-Bildschirm" wählen → "Hinzufügen" tippen.
💡 Tipp
Wenn du die App aktualisieren willst (z.B. neue Sprüche), einfach die neue HTML-Datei auf GitHub hochladen und die alte ersetzen. Die App auf dem Handy aktualisiert sich automatisch.
